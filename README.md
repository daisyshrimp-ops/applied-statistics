# Команда 10 · Прикладная статистика

Три исследования на marimo: белое вино, собственные генераторы и UICrit.

## Эта версия

- Тексты главных экранов взяты из предоставленного архива коллеги; обложка второго спринта обновлена по макету с бутылкой белого вина. Оформление блоков согласовано с ним; первый спринт сохраняет структуру исходного сайта.
- Авторские формулировки и выводы берутся из исходных ноутбуков без переписывания. Подготовительные блоки не показываются; исходные ноутбуки остаются доступны для скачивания. Код — в конце соответствующего раздела.
- Исходные статичные дубли заменены живыми графиками: переключение показателей, способов построения гистограммы, KDE и галочки для отдельных моделей. Описательные статистики сохранены.
- Во втором спринте: выбор алгоритма, n, seed, числа столбиков, кнопка новой выборки, переключение на Q–Q и разность CDF. Добавлены инструкция и обозначения.
- В UICrit: числовые карточки случайно выбранного экрана, таблицы описательных статистик, проверка нормальности при исходном α = 0,05 и с поправкой Холма, масштабируемый график средних экранов с ID точек и карточкой выбора. Таблица и график раздела 4.1 сохранены из Colab. Таблица состава групп стоит перед выводом. В 6.2 — две панели эстетики и удобства с 95% бутстрэп-интервалами из Colab, галочками групп и интервалов. Матрица корреляций — тепловая карта с переключением Пирсона/Спирмена. Таблицы тем и источников стоят рядом. Пустые якорные карточки удалены; текст читается внутри общего белого раздела, как на исходном сайте. Ползунки компактные, белые разделы разделены отступом.
- Полное оглавление UICrit открывает нужные внутренние вкладки. Подготовительные пункты исключены из навигации, остальные разделы и выводы доступны.
- Пасхалка и индикатор чтения сохранены. Встроенный runtime используется и локально, и при экспорте.

## Обновить GitHub Pages

1. Распакуйте архив и загрузите **всё содержимое** в корень репозитория `daisyshrimp-ops/applied-statistics` с заменой файлов. Одного CSS недостаточно.
2. В GitHub Actions дождитесь зелёного **Deploy site**. Существующий workflow вызывает `python tools/build_site.py`.
3. Обновите страницу Ctrl+F5.

`site/` в архив не включается: Actions собирает его самостоятельно. Эта версия не опубликована автоматически.

## Локальный запуск

На Windows запустите `START_WINDOWS.bat`: он установит зависимости, соберёт актуальный `lab01.py` и откроет marimo.

Ручной запуск из каталога проекта:

```bash
python -m pip install -r requirements.txt
python tools/compose_site.py
python -m marimo run lab01.py
```

Для пересборки исходных выводов и HTML/WASM:

```bash
python tools/build_site.py
```

Проверки:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q tests
python tools/verify_refined.py
python tools/verify_embedded_figures.py
```

Результаты проверок и ограничения описаны в `VERIFICATION.md`.

## Исправление незагрузившихся графиков

Оставшиеся 12 уникальных графиков второго спринта и UICrit теперь строятся при запуске из исходного кода ячеек ноутбуков. Данные, seed, алгоритмы, масштабы и единицы сохранены; цвета согласованы с винной и голубой палитрами сайта. Результат встраивается в страницу и не зависит от путей к PNG. Существующие живые графики и их управление сохранены. Архивные 48 исходных PNG остаются в проекте для воспроизводимости, но больше не используются как видимые графики отчёта.

В окнах исследований управление стоит непосредственно перед соответствующим графиком, после пояснений и таблиц. У нормальности убран переключатель α: используется 0,05 из ноутбука.

В UICrit вопрос и гипотеза оформлены одним окном браузера. Пояснение случайного экрана расположено в панели с кнопкой без повторяющейся подписи.
