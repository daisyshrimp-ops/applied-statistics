# Lab01 · Белое вино + дополнительное исследование красного

Готовый интерактивный отчёт первого спринта на marimo. Исследуются pH,
остаточный сахар и объёмная доля спирта в 4898 образцах Wine Quality.
Дополнительно выполнено исследование сахара и спирта у 1599 красных вин и сравнение с белыми.

## Если проект уже запускался

Остановите сайт через Ctrl+C, скопируйте новые файлы поверх старых в `lab01-site`
и сохраните своё окружение `.venv312` (в архив оно не включено). Запустите:

```powershell
.\.venv312\Scripts\python.exe -m marimo run lab01.py
```

Перейдите к пункту **7 · Доп. КТиД · Красное вино** в левом оглавлении.
Устанавливать библиотеки заново для этого раздела не требуется.

## Дополнительное исследование

Изучены остаточный сахар (г/л) и содержание спирта (% об.) красного вина:
случайная природа, EDA, нормальность, зависимость, сравнение с белым вином,
анализ чувствительности к полным повторам и отдельная таблица критериев.

- `extra_ktid_red_vs_white.ipynb` — выполненный ноутбук с сохранёнными таблицами и графиками.
- `wine_comparison.py` — общие расчёты дополнительного исследования.
- `tools/extra_study.py` — тексты и шаблоны раздела сайта.
- `tools/build_extra_notebook.py` — воспроизводимая сборка и выполнение ноутбука.
- `tests/test_extra_study.py` — проверки существенных выводов и обработки данных.
- `reports/red_white_metrics.json` — числовые результаты и SHA-256 исходных CSV.

В сравнении можно менять величину, число столбиков, увеличение области графика
и удаление полных повторов. При смене режима меняются числа, графики и выводы;
EDA выше остаётся основным анализом всех исходных строк.

**Генератор в допзадании намеренно отложен** до работы инфохимиков.
Красный и белый CSV — разные наборы образцов одной коллекции UCI.

Проверки и пересборка дополнительного исследования:

```bash
python -m unittest discover -s tests -v
python tools/build_extra_notebook.py
python tools/build_from_ipynb.py sources/lab1_final_ready_to_submit.ipynb .
python tools/build_site.py
```

## Быстрый запуск в Windows

1. Распакуйте **весь** архив в отдельную папку.
2. Откройте папку `lab01-site` и запустите `START_WINDOWS.bat`.
3. При первом запуске установятся зависимости. Откроется отчёт в браузере.
   Окно терминала оставьте открытым; для остановки нажмите Ctrl+C.

Нужен Python 3.11–3.13 с доступом к pip. Если автоматический запуск не сработал,
откройте терминал в папке `lab01-site` и выполните:

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m marimo run lab01.py
```

На Linux/macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m marimo run lab01.py
```

Для редактирования замените `run` на `edit`.

## Что изменилось

- Сохранены цвета, обложка и общий стиль исходного сайта.
- Рабочая область шире; выводы читаются единым рассказом без отдельной рамки
  вокруг каждого абзаца. Основной текст не находится во внутренних скроллерах.
- Статистики расположены в адаптивной сетке; длинные таблицы не сжимают текст.
- Порядок исследования и выводы перенесены из комплектного исходного `.ipynb`:
  природа величины → EDA → распределение и математическая база → стандартизация →
  связи → состоятельность → отбор выборок → гипотезы → итог по величине.
- Код закрыт по умолчанию. Стрелка под разделом открывает **и закрывает**
  соответствующую реализацию. Общие функции доступны в разделе 6.
- Добавлены плавные якорные переходы, переход к следующей величине и адаптация
  к узким экранам. При системной настройке уменьшения анимации переходы мгновенные.
- Сохранены все исходные элементы управления, расчёты, LaTeX и таблицы критериев.
- CSV уже включён: скачивать его отдельно или обращаться к UCI при запуске не нужно.

## Собранный сайт и публикация

Для просмотра папки `site` без серверного Python-ядра:

```bash
python -m http.server --directory site 8000
```

Откройте http://localhost:8000. Не открывайте `index.html` двойным щелчком:
браузерному Python нужен HTTP. При первом открытии WASM-версии требуется интернет
для загрузки Pyodide и научных пакетов; последующие вычисления выполняются в браузере.
Для локального `marimo run` Pyodide не нужен.

Пересборка сайта после изменения кода или стилей:

```bash
python tools/build_site.py
```

В папке `.github/workflows` сохранён сценарий GitHub Pages.
Если содержимое **папки lab01-site** размещено в корне репозитория,
выберите Settings → Pages → Source → GitHub Actions. Публикация произойдёт после
push в main. Реальная история исследования не создаётся автоматически.

## Обновление исходного ноутбука

```bash
python tools/build_from_ipynb.py sources/lab1_final_ready_to_submit.ipynb .
python tools/build_site.py
```

Команда перезаписывает `lab01.py`. Изменения структуры вносите в шаблоны
`tools/build_from_ipynb.py`, изменения оформления — в `style.css`.
Генератор использует номера ячеек текущей версии ноутбука: после добавления
или удаления ячеек нужно обновить словарь RV и индексы общих разделов.

## Объём работы

Это **первый спринт**: исследование трёх величин до реализации датчика.
Генераторы, их интерактивный интерфейс и автотесты второго спринта здесь не
выдаются за выполненные. Дополнительное исследование КТиД по красному вину выполнено без генератора.
Стандартизация не превращает ненормальные данные в стандартное нормальное
распределение; это явно отмечено в тексте и критериях.

При изменении интерактивных параметров пересчитываются графики, числовые карточки
и вердикты. Авторские выводы из исходного ноутбука описывают исходные настройки
(в гипотезах: n=500, seed=42); интерфейс напоминает об этом.
